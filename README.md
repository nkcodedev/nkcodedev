### [Resili](https://github.com/nkcodedev/resili)

Bounds failure in production Node.js services so retries, timeouts, and downstream outages stay isolated.

Retry, timeout, circuit breaker, bulkhead, rate limiter, Fetch / Axios / Undici adapters, and a plugin system.

### [AgentGauge](https://github.com/nkcodedev/agentgauge)

Shows how LLM agents behave in production: tokens, estimated cost, latency, models, and failures. Prompts and completions are not stored by default.

Node SDK, self-hosted API, PostgreSQL, and a dashboard. Automatic instrumentation for OpenAI, Anthropic, and Gemini, with live dashboard updates over SSE. Cost is estimated server-side from effective-dated model pricing.

[![npm @agentgauge/node](https://img.shields.io/npm/v/@agentgauge/node?style=flat-square&label=%40agentgauge%2Fnode)](https://www.npmjs.com/package/@agentgauge/node)
[![license Apache-2.0](https://img.shields.io/github/license/nkcodedev/agentgauge?style=flat-square)](https://github.com/nkcodedev/agentgauge/blob/main/LICENSE)

Pre-1.0. License: Apache-2.0.

```bash
npm install @agentgauge/node
```

### [Pullsense](https://github.com/nkcodedev/pullsense)

Reviews pull requests with Ollama or OpenAI and posts a check run plus inline comments on the pull request.

MCP works in both directions: a server for Cursor and Claude Desktop, and a client that can add context from other MCP servers to the review. Self-hosted application. License: ISC.
